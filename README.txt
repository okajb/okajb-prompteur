OKAJB PROMPTEUR V1.4 – application PUBLIABLE sans musique privée

1. Publier UNIQUEMENT les fichiers contenus dans ce dossier sur un dépôt GitHub Pages.
2. Ouvrir le site HTTPS depuis Safari iPhone, puis Partager > Sur l’écran d’accueil.
3. Télécharger séparément le fichier PRIVE OKAJB_BIBLIOTHEQUE_PRIVEE_13_TITRES.okajb dans Fichiers (iPhone).
4. Ouvrir l’application installée > Mes chansons > Choisir ma bibliothèque OKAJB (.okajb).
5. Sélectionner le fichier .okajb dans Fichiers et patienter jusqu’au message « 14 titres importés » (13 complets + « Écoute ton jazz » en attente).
6. Les sons sont stockés en local via IndexedDB. Aucun MP3 ni texte de paroles privé n’est publié sur GitHub.
7. GARDER le fichier original .okajb sur un autre support. Faire périodiquement « Sauvegarder toute ma bibliothèque ».
8. Pour filmer, autoriser caméra et micro. Sur iPhone, tester avec un clip court; compatibilité de la capture et du format à valider sur l’appareil. La sauvegarde dans Photos passe par le partage iOS, pas une écriture automatique.

Les paroles défilent selon le curseur temporel de la musique (début/durée réglables séparément par version) : ce n’est pas une reconnaissance automatique des mots.
Aucun MP3 ne quitte le navigateur au cours de l’import. Les données locales du navigateur peuvent disparaître : exporter une sauvegarde.

ATTENTION : ne jamais téléverser le fichier PRIVE .okajb sur le site, GitHub ou un dépôt public.
